## 🔐 Authentication Required

When you push, GitHub will ask for credentials:

### Username
```
sunnylingampelly
```

### Password
**Don't use your GitHub password!** Use a Personal Access Token instead.

#### Get Your Token:
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name it: "LinkKart Push"
4. Select scope: ✅ `repo` (full control of private repositories)
5. Click "Generate token"
6. **Copy the token** (looks like: `ghp_xxxxxxxxxxxx`)

#### Use the Token:
- When prompted for password, **paste the token**
- The token is your password
