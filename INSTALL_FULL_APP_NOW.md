## 📱 QUICK START

After installing:

1. **Open app** → Splash screen
2. **Tap "Get Started"** on welcome screen
3. **Enter phone**: Any 10 digits (e.g., 9876543210)
4. **Enter OTP**: 123456
5. **Create store**: 
   - Name: Your Store Name
   - Logo: Optional (tap to upload)
6. **Dashboard opens** → You're in! 🎉

---

## 🛍️ ADD YOUR FIRST PRODUCT

1. **Tap Products tab** (bottom navigation)
2. **Tap + button** (bottom right)
3. **Fill details**:
   - Product name
   - Price
   - Description
   - Stock quantity
   - Upload image
4. **Tap Save**
5. **Product appears** in list! ✅
