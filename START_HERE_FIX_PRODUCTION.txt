PROBLEM:
--------
Product creation failing with "API Error: 500 - DATABASE_ERROR"

ROOT CAUSE:
-----------
Backend using hardcoded database credentials (localhost/root/no password)
instead of your production database credentials.

SOLUTION (3 STEPS):
-------------------

┌─ STEP 1: CHECK CURRENT STATUS ────────────────────────────────────────────┐
│                                                                            │
│  Open this URL in your browser:                                           │
│  https://api.linkkart.shop/api/check-db                                   │
│                                                                            │
│  This shows:                                                               │
│  • Current database settings                                              │
│  • Connection status                                                       │
│  • What tables exist                                                       │
│  • What needs fixing                                                       │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ STEP 2: UPDATE PRODUCTION .ENV FILE ─────────────────────────────────────┐
│                                                                            │
│  SSH into your server:                                                     │
│  $ ssh your_user@your_server                                              │
│  $ cd /path/to/backend                                                     │
│  $ nano .env                                                               │
│                                                                            │
│  Update these lines with YOUR ACTUAL credentials:                         │
│                                                                            │
│  DB_HOST=localhost                                                         │
│  DB_DATABASE=linkkart                                                      │
│  DB_USERNAME=your_actual_db_username                                       │
│  DB_PASSWORD=your_actual_db_password                                       │
│                                                                            │
│  Save: Ctrl+X, then Y, then Enter                                          │
│                                                                            │
│  Don't know your credentials? Check cPanel → MySQL Databases              │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ STEP 3: UPLOAD FIXED BACKEND FILES ──────────────────────────────────────┐
│                                                                            │
│  Upload these 2 files to your production server:                          │
│  • backend/public/index.php                                               │
│  • backend/public/api.php                                                 │
│                                                                            │
│  Using FileZilla/FTP:                                                      │
│  1. Connect to your server                                                │
│  2. Navigate to /public_html/backend/public/                              │
│  3. Upload both files (overwrite existing)                                │
│                                                                            │
│  OR using Git:                                                             │
│  $ git add backend/public/*.php                                           │
│  $ git commit -m "Fix database connection"                                │
│  $ git push                                                                │
│  (then git pull on production server)                                      │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
