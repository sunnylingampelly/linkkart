COMMON ISSUES:
==============

Issue 1: "Product Sizes: null"
-------------------------------
Problem: API not returning sizes
Fix: Check backend api.php - ensure sizes are in response

Issue 2: "Product Sizes: {}"
-----------------------------
Problem: Sizes saved as empty JSON
Fix: Check add_product_screen - ensure _sizes has values

Issue 3: "Merging product sizes..." not shown
----------------------------------------------

Fix: Check Product model parsing

Issue 4: Controllers created but show 0

Fix: Check if product.sizes keys match _sizes keys (case sensitive!)
