🚨 TROUBLESHOOTING:

Images not showing?
  1. Check backend running: curl http://localhost:8000/api/health
  2. Check database: php check_current_stores.php
  3. Check browser console (F12) for errors

CORS errors?
  - Backend should have CORS headers enabled
  - Check backend/public/index.php

Port already in use?
  - Backend: Use php -S localhost:8001
  - Storefront: set PORT=3001 && npm start
