🚨 QUICK FIX (If You Have Existing Stores):

Generate avatar images from store names:

  UPDATE stores 
  SET logo = CONCAT(
      'https://ui-avatars.com/api/?name=',
      REPLACE(name, ' ', '+'),
      '&size=400&background=D4AF37&color=fff&bold=true'
  )
  WHERE deleted_at IS NULL 
  AND (logo IS NULL OR logo = '' OR logo NOT LIKE 'http%');

This creates beautiful letter avatars!
