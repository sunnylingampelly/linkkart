## 📱 WhatsApp Integration

### How It Works:

1. **Customer clicks "Order on WhatsApp"**
2. **Opens WhatsApp with pre-filled message:**
   ```
   Hi! I'm interested in [Product Name] from [Store Name].
   Price: ₹[Price]
   Link: [Product URL]
   ```
3. **Customer sends message to store owner**
4. **Store owner responds and completes order**
